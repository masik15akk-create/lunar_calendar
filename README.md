# 🌙 Lunar Calendar (Phases) — узнай фазу Луны в любой день

> «Луна всегда рядом — узнай её настроение»

**Lunar Calendar (Phases)** — это набор консольных утилит для расчёта и отображения фаз Луны на заданную дату.  
Программа вычисляет возраст Луны, процент освещённости и определяет текущую фазу (новолуние, первая четверть, полнолуние, последняя четверть) с ASCII-визуализацией.

## 🚀 Особенности
- 🌑 Определение фазы Луны для любой даты (по умолчанию сегодня).
- 📊 Расчёт возраста Луны в днях и процента освещённости.
- 🎨 ASCII-графика для визуализации фазы (в терминале).
- 📅 Поддержка дат в формате ГГГГ-ММ-ДД.
- 🗓️ Показ фаз на весь текущий месяц (опционально).
- 🖥️ Цветной вывод в терминале (где реализовано).

## 🛠️ Установка и запуск

Для каждого языка — минимальные зависимости (в основном стандартные библиотеки).

| Язык       | Зависимости                          | Команда запуска                         |
|------------|--------------------------------------|-----------------------------------------|
| Python     | стандартная библиотека               | `python lunar_calendar.py`              |
| Go         | стандартная библиотека               | `go run lunar_calendar.go`              |
| JavaScript | Node.js, `fs`, `readline`            | `node lunar_calendar.js`                |
| Java       | стандартная библиотека               | `javac lunar_calendar.java && java lunar_calendar` |
| C#         | .NET (или mono)                      | `dotnet run`                            |
| Rust       | `chrono` (для дат)                   | `cargo run`                             |
| Ruby       | `date` (стандартная)                 | `ruby lunar_calendar.rb`                |
| PHP        | стандартная библиотека               | `php lunar_calendar.php`                |
